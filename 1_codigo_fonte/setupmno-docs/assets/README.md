# Assets de documentação

Local reservado para imagens, diagramas, GIFs e referências de vídeo que
possam ser publicados futuramente no manual e no Help.

Regras:

- nunca capturar credenciais, e-mails, tokens, IPs ou domínios de clientes;
- preferir ambientes fictícios ou de homologação;
- registrar origem, licença e data de cada asset;
- manter uma alternativa textual acessível;
- otimizar tamanho antes de qualquer inclusão no Control Center;
- não empacotar automaticamente esta pasta no runtime.
