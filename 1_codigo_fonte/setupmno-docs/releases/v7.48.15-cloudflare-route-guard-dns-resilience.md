# Release Note v7.48.15 - Proteção Cloudflare Route Guard e Resolução Resiliente de DNS

**Data:** 17 de Setembro de 2026  
**Versão:** `v7.48.15`  
**Escopo:** Mautic 7/6/5/4, Evolution API, Chatwoot Combos, N8N, Typebot, Flowise, Dify e todos os 157 setups do Setup MNO.

---

## 1. Contexto e Motivação

Durante a homologação em servidores limpos (Hetzner VPS e WSL2) operando via terminal remoto do Control Center, foram identificados dois comportamentos que impactavam a experiência do usuário:

1. **Ausência do Route Guard no Mautic e scripts de apps:** Ao instalar o Mautic ou outras aplicações, se o subdomínio informado já estivesse em uso em outro servidor ou Tunnel da mesma conta Cloudflare, o script deletava silenciosamente o registro DNS anterior e sobrescrevia a rota, sem consultar o usuário com as opções interativas de `VOLTAR` ou `SOBRESCREVER`.
2. **Falso Negativo de Resolução DNS:** Imediatamente após a criação do CNAME via Cloudflare API, uma chamada única a `nslookup "$url"` consultava o resolver local `systemd-resolved` (`127.0.0.53`). Antes da propagação nos resolvers intermediários, o resolver retornava `NXDOMAIN` e armazenava no cache negativo local temporário. Isso disparava a tela de aviso *"AVISO: O domínio ... não está resolvendo. Verifique a configuração do Cloudflare Tunnel."*, mesmo quando a aplicação já estava 100% ativa, funcional e acessível no mundo exterior (HTTP 200/302).

---

## 2. Solução Implementada

### A. Guardião de Rotas Cloudflare (`cloudflare_app_guard.sh`)
- Implementada a função `setupmno_guard_route "$hostname"`:
  - Consulta instantânea via API Cloudflare na Zona DNS (`/zones/${CLOUDFLARE_ZONE_ID}/dns_records?name=${hostname}`).
  - Se livre (`count == 0`): Prossegue silenciosamente em frações de segundo.
  - Se já utilizado (`count > 0`): Exibe diálogo modal interativo Whiptail:
    - **`VOLTAR`** (Código `20`): Permite ao usuário retornar imediatamente ao campo de digitação e escolher outro subdomínio (RECOMENDADO).
    - **`SOBRESCREVER`** (Código `0`): Permite transferir o subdomínio conscientemente para a aplicação atual com snapshot e proteção.
    - **`CANCELAR`** (Código `130`): Encerra a instalação sem efetuar nenhuma alteração no DNS ou nos servidores.
- Cache de validação por sessão (`SETUPMNO_GUARDED_HOSTNAMES`) para evitar diálogos repetidos.

### B. Validação Resiliente de Resolução DNS (`setupmno_check_dns`)
- Implementada a função `setupmno_check_dns "$domain" [max_attempts=8]`:
  - **Loop com retry progressivo:** Realiza até 8 tentativas (com intervalo de 2s) para eliminar 100% dos falsos negativos de propagação.
  - **Múltiplos resolvers DNS de alta velocidade:** Consulta sequencialmente `1.1.1.1` (Cloudflare Anycast direto), `8.8.8.8` (Google Public DNS) e o DNS local.
  - **HTTP Curl Probe:** Probe HTTP direto (`curl -s -k -I https://$domain`) com timeout curto; se o proxy da Cloudflare responder (HTTP 200, 301, 302, 401, etc.), o DNS é considerado validado imediatamente, contornando qualquer cache negativo residual do host.

### C. Wrapper Global Transparente para Todos os 157 Setups
- Exportada a função wrapper `nslookup()`:
  - Intercepta chamadas de 1 argumento de hostname (`nslookup "$url"`).
  - Executa de forma transparente `setupmno_check_dns "$1" 8`.
  - Herança automática em todos os 157 scripts de instalação via `cloudflare_credentials` e `install.sh`.
