# v7.36.2 estável — Correção do build do Control Center

- Estado documental: `validated`
- Maturidade da release: `stable`
- Maturidade da funcionalidade SRE-5: `beta`
- Versão estável homologada: Setup MNO 7.36.2 / Control Center 4.36.2
- Ambientes: WSL2 AMD64 e VPS ARM64

## Para iniciantes

A v7.36.1 levou o novo filtro de qualidade até o pacote, mas esqueceu um dos
arquivos necessários na caixa usada para construir o painel. É como enviar uma
receita sem uma das páginas: o instalador percebeu a ausência, interrompeu a
troca e manteve a versão anterior funcionando.

A v7.36.2 inclui a página que faltava e acrescenta uma conferência automática:
todo arquivo Go de produção precisa estar tanto no `Dockerfile` quanto no pacote
de fontes. Se algo faltar, a geração da distribuição é bloqueada antes de chegar
ao usuário.

## O que mudou

- `assistant_output_gate.go` entra no build Docker e no pacote de fontes;
- o gerador inventaria dinamicamente os arquivos Go de produção;
- cada arquivo do inventário é validado no `Dockerfile` e no pacote gerado;
- versões Setup MNO e Control Center avançam para 7.36.2 e 4.36.2.

Permanecem iguais o gate BETA, o SRE-5 BETA, os planos, credenciais, volumes,
redes e a regra de não executar correções pela IA.

## Segurança, falhas e rollback

Nenhuma permissão foi ampliada. A reconciliação continua transacional: falha de
build preserva os serviços anteriores. Para desfazer esta release, reinstale a
versão estável anterior v7.35.0 pelo fluxo oficial; não remova volumes, secrets
ou stacks manualmente.

## Teste no WSL2

1. Mantenha o Docker Desktop ativo e atualize para a v7.36.2.
2. Resultado esperado: a imagem 4.36.2 é construída e os quatro serviços do
   Control Center atingem `1/1` sem rollback.
3. Abra Visão geral e confirme Setup MNO 7.36.2 e Control Center 4.36.2.
4. No Assistente BETA, execute uma análise e confirme resposta normal ou
   fallback local seguro.
5. Sinal de falha: diálogo de sincronização, réplica `0/1`, erro HTTP 502 ou
   versões divergentes.

## Teste na VPS

Repita a atualização em VPS AMD64 ou ARM64. Aguarde até cinco minutos para a
convergência em ARM64. O resultado esperado é o mesmo do WSL2; lentidão de build
não deve ser confundida com falha enquanto as tarefas ainda estiverem iniciando.

## Homologação e promoção

Francis MNO validou a release no WSL2 x86-64 e em VPS ARM64 e declarou
explicitamente a v7.36.2 como estável em 27/08/2026. A promoção da release não
remove a etiqueta **BETA** do SRE-5, do Assistente MNO ou dos Blueprints.

## Como explicar para a comunidade

“A atualização anterior foi bloqueada porque faltou um arquivo na montagem do
painel. O Setup MNO protegeu o ambiente e manteve a versão anterior. A v7.36.2
corrige o pacote e passa a impedir automaticamente esse tipo de esquecimento.”
