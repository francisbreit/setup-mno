# Notas de evolução

Esta pasta registra, a partir da adoção da documentação contínua, o contexto
humano de cada etapa ou feature. O histórico Git continua sendo a fonte dos
commits e tags; estes documentos explicam experiência, riscos, testes e
rollback que não cabem em uma mensagem de commit.

Formato recomendado:

```text
vX.Y.Z-nome-curto.md
```

Enquanto uma versão ainda não foi definida, use:

```text
planejado-nome-curto.md
```

O arquivo deve apontar para os documentos detalhados relacionados e declarar
claramente `draft`, `implemented`, `validated` ou `published`.
