## Resumo para leigos

Foi criada uma escola operacional dentro do código-fonte do projeto. Ela ensina
como investigar Linux, WSL2, Docker Desktop, Swarm, Traefik, Cloudflare, backup
e incidentes sem entregar o servidor a uma IA. Essa escola ainda não aparece no
Control Center e não instala nenhum scanner ou agente.

## Objetivo e critérios de sucesso

- Objetivo: concluir o marco `SRE-0` com conhecimento humano versionado,
  rastreável e preparado para adaptação futura ao Help.
- Evidência esperada: nove documentos inventariados, hashes válidos, fontes
  oficiais HTTPS e teste de adulteração bloqueado.
- Condição de falha: arquivo ausente, extra, alterado, symlink, path fora do
  pack, fonte não permitida, metadado obrigatório ausente ou possível segredo.

## Jornada do usuário

1. O mantenedor abre `setupmno-docs/sre/README.md`.
2. Segue a trilha na ordem sugerida.
3. Usa os exemplos somente leitura para entender as camadas.
4. Executa o validador antes de revisar uma mudança documental.
5. Publica no Help apenas trechos selecionados e adaptados em uma etapa futura.

## Arquitetura e dados

O pack é composto por Markdown e `manifest.json`. O validador Python usa apenas
a biblioteca padrão e lê exclusivamente a árvore indicada. Não há banco, stack,
rede, porta, secret, mount, Docker socket, chamada de API ou telemetria.

## Permissões e planos

Os arquivos pertencem ao repositório de construção. Eles não são enviados aos
clientes e não concedem acesso a telas. A governança e a seleção editorial
permanecem exclusivas do PRO MASTER; proteções críticas descritas nos textos
valem para todos os planos.

## Segurança e privacidade

Os exemplos usam nomes fictícios e não coletam dados. O validador não acessa a
rede. A documentação reafirma a proibição de root, sudo, grupo Docker, Docker
socket, shell e credenciais para LLMs.

## Rollback

Como não há alteração de runtime, o rollback consiste em reverter o commit dos
documentos. Nenhum volume, banco, serviço, DNS ou instalação de cliente precisa
ser restaurado. Francis MNO promoveu explicitamente a v7.31.0 como última
versão estável em 2026-08-24; a tag existente permaneceu imutável.

## FAQ e falhas conhecidas

- **O pack já é o especialista SRE?** Não. É a base humana do especialista.
- **Ele aparece no Help?** Não. A publicação será editorial e separada.
- **O teste prova que todo conselho é correto?** Não. Prova integridade,
  inventário e regras estruturais; revisão humana e atualização das fontes
  continuam obrigatórias.
- **Posso rodar o validador na instalação `/root/SetupLowCodeMno`?** Não é o
  alvo. O pack existe somente no repositório de construção.
