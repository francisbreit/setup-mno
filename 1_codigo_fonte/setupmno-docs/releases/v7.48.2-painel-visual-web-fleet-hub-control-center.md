# Release v7.48.2 — Painel Visual Web do Fleet Hub no Control Center

- **Data da Release:** 15 de Setembro de 2026
- **Versão do Setup MNO:** `v7.48.2`
- **Versão do Control Center:** `v4.44.5`
- **Maturidade das Features:** `beta` (MNO Fleet Hub e Fleet Clone Web)
- **Ambientes Homologados:** WSL2 (Windows 10/11 x86_64) + Docker Desktop, VPS Hetzner / Oracle (ARM64 e x86_64)
- **Compatibilidade:** Debian 11/12/13, Ubuntu 20.04/22.04/24.04

---

## 1. Resumo Executivo da Release

A versão **v7.48.2** do Setup MNO e **v4.44.5** do Control Center conclui a **Opção 3 do Roadmap de Evolução Técnica**: a disponibilização do **Painel Visual Web do MNO Fleet Hub**. 

Anteriormente, o Fleet Clone e as rotinas de backup e restauração portátil de stacks e combos eram operados exclusivamente através do menu de terminal Bash / Whiptail (`install.sh -> 4 Gerenciador e Migrador de Frota`). Com esta release, toda a inteligência de clonagem, migração assistida, verificação prévia (*preflight*) de recursos (RAM, CPU e disco) e criação de backups portáteis `.tar.gz` pode ser executada graficamente de forma intuitiva no navegador através do Setup MNO Control Center.

---

## 2. Principais Funcionalidades Entregues

### 2.1. Botão e Acesso Rápido no Card da Frota
- Na seção **MNO Fleet Hub** do Control Center, cada nó cadastrado e online agora exibe o botão **"Clonar / Migrar App"** (`#fleet-clone-btn`).
- O botão é protegido por segregação de plano: usuários no plano `Free` recebem aviso visual de funcionalidade exclusiva e modal de upgrade para `PRO`, garantindo monetização ética e sem falhas de runtime.

### 2.2. Modal Inteligente de Clonagem e Migração (`#fleet-clone-dialog`)
- **Inspeção Estrutural Dinâmica:** Ao abrir o diálogo, o frontend consulta `/api/fleet/nodes/{id}/structure` e lista com ícones e metadados todas as stacks ativas no nó de origem, classificando-as entre combos integrados e ferramentas individuais.
- **Gaveta de Apps do Combo:** Permite expandir a composição de combos complexos (ex: Typebot Viewer + Builder, Chatwoot + Evolution + RabbitMQ).
- **Seleção de Destino com Bloqueio de Origem:** Dropdown com todos os nós online da frota, desabilitando automaticamente o nó de origem para impedir migrações circulares acidentais.
- **Preflight em Tempo Real:** Verifica CPU, RAM livre e espaço em disco no nó de destino antes de permitir a confirmação da operação.
- **Freeze de Segurança Opcional:** Checkbox para pausar a stack de origem durante a transferência, garantindo zero perda de mensagens ou dados em produção.

### 2.3. Modal de Backup Portátil (`#fleet-backup-dialog`)
- Permite gerar snapshots portáteis e compactados (`.tar.gz`) de stacks completas ou individuais com 1 clique, integrando dumps relacionais e cópias de volumes.
- Exibe o caminho absoluto do artefato gerado no servidor para fácil download via SFTP ou migração externa.

### 2.4. Reconhecimento Local da Torre Master (`node-master`)
- O backend em Go (`fleet_transfer.go`) foi corrigido para tratar o identificador especial `node-master` como o nó local da Torre Master, executando a inspeção diretamente via CLI Docker local sem exigir conexão SSH remota contra si mesmo.
