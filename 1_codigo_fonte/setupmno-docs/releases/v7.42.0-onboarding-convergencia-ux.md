# Release Candidate v7.42.0 — Onboarding e Convergência UX para Produção

- Versão Setup MNO: `7.42.0` (candidata em homologação)
- Versão Control Center: `4.42.0`
- Maturidade: `BETA`
- Data: Agosto/2026

## O que foi implementado

1. **Jornada de Onboarding Interativa (4 Passos):**
   - Modal guiado com checklist de primeiro acesso (Saúde do Servidor, Serviços Base, Primeiro Deploy e Segurança/Resiliência);
   - Persistência de conclusão em `localStorage`, permitindo dispensar ou revisitar a qualquer momento via Dashboard ou Help.
2. **Convergência UX e Acessibilidade (Desktop & Android):**
   - Otimização responsiva para smartphones (Android e iOS) e tablets;
   - Navegação por teclado aprimorada com foco visível e fechamento de modais via `Escape`;
   - Cartão de acesso rápido "Primeiros Passos" no Dashboard principal.
3. **Resiliência e Fallback de Interface:**
   - Mensagens claras de sincronização durante inicialização ou recarga do agente somente leitura;
   - Tooltips e links contextuais conectando recursos ao Help didático.
