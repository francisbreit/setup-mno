# Research Brief: Setup MNO Competitive Analysis

**Date:** 2026-07-15
**Question:** Existe alguma solução no mercado tão completa quanto o Setup MNO para deploy de aplicações Docker? Quais são as dores do mercado e como tornar o Setup MNO imbatível?

## Setup MNO Architecture (Context)
- Docker Swarm + Traefik + Portainer + PostgreSQL + Redis + PgBouncer (essenciais)
- 65+ aplicações (apps individuais)
- Combos pré-integrados (ex: Chatwoot + Evolution + RabbitMQ + MinIO)
- Suporte a dois modos: Tradicional (Traefik) e Cloudflare Tunnel
- Detecção automática WSL2 vs VPS
- DNS automático via Cloudflare API
- Planos: Free, Free1, Free2, Pro, Trial Pro
- Licenciamento via SHC (binários compilados)

## Scope
- Concorrentes diretos e indiretos
- Dores não resolvidas no mercado
- Oportunidades de diferenciação
- Tendências emergentes (2025-2026)

## Angles
1. One-click deploy platforms (Coolify, CapRover, Portainer + templates)
2. PaaS modernos (Railway, Render, Fly.io, DigitalOcean App Platform)
3. Hosting panels com app store (Hostinger, Plesk, CloudPanel)
4. Self-hosted alternatives (Yacht, Homarr, Umbrel)
5. Dores do mercado e gaps não resolvidos
6. Tendências emergentes (AI deployment, GitOps, edge computing)
