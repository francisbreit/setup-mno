# F5: Market pain points and unmet needs

## Findings

### [1] Docker Swarm is perceived as complex and enterprise-oriented, pushing small users toward Compose
- quote: "Swarm mode is an advanced feature for managing a cluster of Docker daemons. Use Swarm mode if you intend to use Swarm as a production runtime environment. If you're not planning on deploying with Swarm, use Docker Compose instead."
- url: https://docs.docker.com/engine/swarm/
- source_type: primary
- published: unknown
- confidence: high

### [2] Docker Compose has recurring networking and build issues across recent versions
- quote: "Networking seems broken in 2.40.3" / "Building with bake hangs indefinitely"
- url: https://github.com/docker/compose/issues/13348
- source_type: primary
- published: 2025-11-04
- confidence: high

### [3] Docker Swarm lacks IPv6 DNS support, a critical gap for modern deployments
- quote: "Feature request: IPv6-enabled embedded DNS server" — closed as "Not planned"
- url: https://github.com/moby/moby/issues/48125
- source_type: primary
- published: 2024-07-09
- confidence: high

### [4] Swarm-to-Compose integration remains broken, users request parity with latest compose format
- quote: "swarm docker-compose integration and/or support latest compose format"
- url: https://github.com/moby/moby/issues/48232
- source_type: primary
- published: 2024-07-24
- confidence: high

### [5] Docker Desktop subscription model creates cost barrier for small businesses (>250 employees or >$10M revenue)
- quote: "Docker Business: $24 per user/month — For enterprises desiring robust security, control, and compliance features."
- url: https://www.docker.com/pricing/
- source_type: primary
- published: 2026
- confidence: high

### [6] Docker on Windows has persistent storage bloat issues requiring manual intervention
- quote: "Docker on Windows: Eating Your C: Drive? How I Reclaimed Over 350GB from Bloated VHDX Files!"
- url: https://dev.to/hamada147/docker-on-windows-eating-your-c-drive-how-i-reclaimed-over-350gb-from-bloated-vhdx-files-11dm
- source_type: community
- published: 2024
- confidence: medium

### [7] Docker is the most admired (78%) and most-desired developer tool, indicating strong adoption but also high expectations
- quote: "Docker users have elevated this tool to most-admired (78%) this year along with being most-desired for the second year in a row."
- url: https://survey.stackoverflow.co/2024/technology
- source_type: primary
- published: 2024-06
- confidence: high

### [8] Swarm lacks CSI plugin support for non-Swarm workloads, limiting storage flexibility
- quote: "CSI plugins support for non-Swarm workloads"
- url: https://github.com/moby/moby/issues/50021
- source_type: primary
- published: 2025-05-17
- confidence: medium

### [9] Self-hosting beginners face steep learning curves with Docker deployment
- quote: "It's Time to Say Goodbye to Docker" — 1090 reactions on DEV.to, highlighting Docker fatigue
- url: https://dev.to/martinheinz/it-time-to-say-goodbye-to-docker-386h
- source_type: community
- published: 2020-10-15
- confidence: medium

### [10] Overlay networking in Swarm has DNS resolution failures in IPv6 environments
- quote: "Docker fails to provide DNS/name/alias to containers in a overlay network when is created with IPv6"
- url: https://github.com/moby/moby/issues/47644
- source_type: primary
- published: 2024-03-27
- confidence: high

## Dead ends
- Reddit blocked all direct fetch attempts (anti-bot verification)
- DuckDuckGo search returned empty pages (JavaScript-rendered content not accessible)
- Google search blocked automated access
- Several blog URLs returned 404 (content farm/SEO pages that have been removed)
