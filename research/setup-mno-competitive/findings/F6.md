# F6: Emerging trends in deployment (2025-2026)

## Findings

### [1] Kubernetes is now the production backbone for both cloud-native apps and AI workloads
- quote: "82% of container users running Kubernetes in production... what was once experimental is now foundational. Today, Kubernetes serves as the common operating layer organizations depend on to run modern, production-grade systems and bring AI into real-world environments."
- url: https://www.cncf.io/reports/the-cncf-annual-cloud-native-survey/
- source_type: primary (CNCF Annual Survey)
- published: 2026-01-20
- confidence: high

### [2] Nearly 20 million developers now work in standardized cloud-native environments; 88% of backend developers use DevOps/platform environments
- quote: "nearly 20 million developers are adopting, standardizing, and scaling cloud native technologies... 88% of backend developers now work in standardized DevOps and platform environments"
- url: https://www.cncf.io/reports/state-of-cloud-native-development-q1-2026/
- source_type: primary (CNCF + SlashData survey)
- published: 2026-03-24
- confidence: high

### [3] Platform engineering and AI-driven workflows are converging as top developer priorities
- quote: "From platform engineering to AI-driven workflows, this report uncovers which tools developers trust most for maturity, usefulness, and reliability... how teams are structuring internal platforms to support modern workloads"
- url: https://www.cncf.io/reports/q1-2026-the-cncf-technology-radar-report/
- source_type: primary (CNCF Technology Radar, 400+ developers)
- published: 2026-03-23
- confidence: high

### [4] Docker is pivoting hard toward AI agent governance: "Your laptop is the new prod"
- quote: "Docker AI Governance: centralized control over how agents execute, what they can reach on the network, which credentials they can use, and which MCP tools they can call... Your laptop is the new production environment"
- url: https://www.docker.com/blog/docker-ai-governance-unlock-agent-autonomy-safely/
- source_type: primary (Docker official blog)
- published: 2026-05-12
- confidence: high

### [5] AI agents are shifting the deployment paradigm: runtime isolation replaces pipeline-based governance
- quote: "Agents don't follow those checkpoints... An agent running on a developer's machine can inspect repositories, execute commands, install packages, access local files, query APIs, and interact with external tools all within a single session. More importantly, it often does so using the same permissions as the person operating it."
- url: https://www.docker.com/blog/your-laptop-is-the-new-production-environment/
- source_type: primary (Docker blog, Docker Captain)
- published: 2026-07-08
- confidence: high

### [6] Hybrid cloud is the dominant deployment model in 2026
- quote: "Why hybrid cloud is becoming the dominant deployment model"
- url: https://www.cncf.io/reports/state-of-cloud-native-development-q1-2026/
- source_type: primary (CNCF + SlashData survey)
- published: 2026-03-24
- confidence: high

### [7] On-prem DBaaS reveals the platform engineering gap: no standard exists for self-service database provisioning in Kubernetes
- quote: "There is still no broadly adopted framework that separates what developers request from how platform teams implement it... organizations continue building similar solutions repeatedly—each with its own APIs, workflows, and operational assumptions"
- url: https://www.cncf.io/blog/2026/07/15/on-prem-dbaas-in-2026-platforms-standards-and-gaps/
- source_type: primary (CNCF blog, anynines)
- published: 2026-07-15
- confidence: high

### [8] WebAssembly is expanding beyond browsers into server and edge computing as a portable compilation target
- quote: "Wasm is designed as a portable compilation target for programming languages, enabling deployment on the web for client and server applications... Wasm supports non-web embeddings"
- url: https://webassembly.org/
- source_type: primary (WebAssembly official site)
- published: unknown (ongoing standard)
- confidence: medium

### [9] Docker's product portfolio now explicitly targets AI infrastructure: Sandboxes, AI Governance, Gordon (AI agent), Model Runner (local LLM), MCP Catalog
- quote: "Docker Sandboxes (isolated environments for coding agents), Docker AI Governance (govern agents and Claws across every team), Gordon (your AI agent across Docker), Docker Model Runner (local-first LLM inference made easy), Docker MCP Catalog and Toolkit (connect and manage MCP tools)"
