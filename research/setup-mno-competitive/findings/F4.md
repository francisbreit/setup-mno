# F4: Self-hosted deploy alternatives

## Findings

### [1] CasaOS has the largest community among all self-hosted deploy managers (36.7k GitHub stars, 2.1k forks)
- quote: "CasaOS - A simple, easy-to-use, elegant open-source Personal Cloud system."
- url: https://github.com/IceWhaleTech/CasaOS
- source_type: primary
- published: unknown (project active since ~2020, latest release v0.4.15 Dec 19, 2024)
- confidence: high

### [2] CasaOS claims access to over 100,000 Docker ecosystem apps, far exceeding any curated app store
- quote: "Over 100,000 apps from the Docker ecosystem can be easily installed"
- url: https://github.com/IceWhaleTech/CasaOS
- source_type: primary
- published: unknown
- confidence: high

### [3] Dockge is the most popular pure Docker Compose stack manager (23.8k stars, 786 forks), created by the Uptime Kuma author
- quote: "A fancy, easy-to-use and reactive self-hosted docker compose.yaml stack-oriented manager"
- url: https://github.com/louislam/dockge
- source_type: primary
- published: latest release 1.5.0 (Mar 30, 2025)
- confidence: high

### [4] Dockge is a compose-only manager with no app store, no reverse proxy, and no security layer -- it is a developer tool, not an end-user deploy accelerator
- quote: "The main objective of Dockge is to try to use the docker compose.yaml for everything. If you want to manage a single container, you can just use Portainer or Docker CLI."
- url: https://github.com/louislam/dockge
- source_type: primary
- published: unknown
- confidence: high

### [5] Umbrel offers 300+ apps in its app store but is licensed under PolyForm Noncommercial 1.0.0, forbidding commercial redistribution
- quote: "You're free to use, fork, modify, and redistribute Umbrel for personal and nonprofit use under the same license."
- url: https://github.com/getumbrel/umbrel
- source_type: primary
- published: unknown
- confidence: high

### [6] Umbrel is evolving into a hardware company (Umbrel Home, Umbrel Pro), making its OS increasingly tied to proprietary hardware
- quote: "umbrelOS is designed for the Umbrel Pro and Umbrel Home, where it includes first-class support for all features. On other devices (like Raspberry Pi or x86 systems), it's freely available with core functionality, but support and feature availability are best-effort"
- url: https://github.com/getumbrel/umbrel/wiki/umbrelOS-on-Umbrel-Home-vs.-DIY
- source_type: primary
- published: Sep 24, 2025
- confidence: high

### [7] Cosmos Server is the only competitor with built-in security layers (SmartShield anti-DDOS, anti-bot, 2FA, OpenID) and a dedicated comparison table vs. alternatives
- quote: "Cosmos is the most secure and easy way to self-host a Home Server. It acts as a secure gateway to your application, as well as a server manager."
- url: https://github.com/azukaar/Cosmos-Server
- source_type: primary
- published: unknown
- confidence: high

### [8] Cosmos Server supports Docker Compose import and has a Terraform provider, but no Docker Swarm support -- same as all other competitors
- quote: "Container management - To easily manage your containers and their settings, keep them up to date as well as audit their security. Includes docker-compose support!"
- url: https://github.com/azukaar/Cosmos-Server
- source_type: primary
- published: unknown
- confidence: high

### [9] Homarr is a dashboard/organizer (4.3k stars), not a deploy tool -- it provides 40+ integrations and 20K+ icons but no container deployment capability
- quote: "A modern and easy to use dashboard. 40+ integrations. 20K+ icons built in. Authentication out of the box. No YAML, drag and drop configuration."
- url: https://github.com/homarr-labs/homarr
- source_type: primary
- published: v1.70.0 (Jul 10, 2026)
- confidence: high

### [10] Yacht (57 stars on the SelfhostedPro fork) is essentially abandoned -- the README explicitly states it has not been updated and the new version is incomplete
- quote: "This applicaton has not been updated in a while, I have brought it up to date as much as possible for security. Under the 'wicked-testdeploy' branch. But this will not fully build."
- url: https://github.com/SelfhostedPro/Yacht
- source_type: primary
- published: unknown
- confidence: high

### [11] Zero out of six competitors offer Docker Swarm support -- all exclusively use Docker Compose, making Setup MNO's Swarm-based orchestration a genuine differentiator
- (Derived from reading all six READMEs and documentation pages)
- url: multiple (see above)
- source_type: primary
- published: 2026-07-15
- confidence: high

### [12] Cosmos Server's license (Apache 2.0 + Commons Clause) and Umbrel's license (PolyForm Noncommercial) both restrict commercial use, unlike Setup MNO's paid-tier model
- quote (Cosmos): "You are not allowed to sell it, a derivative or to sell a service based on it"
- quote (Umbrel): "You're free to use, fork, modify, and redistribute Umbrel for personal and nonprofit use"
- url: https://github.com/azukaar/Cosmos-Server, https://github.com/getumbrel/umbrel
- source_type: primary
- published: unknown
- confidence: high

## Dead ends
- Could not find exact Docker Hub pull counts for Yacht, CasaOS, Cosmos to compare adoption beyond GitHub stars
- CasaOS development appears stalled (last release Dec 2024) despite 36.7k stars -- no active blog posts or announcements found
- None of the competitors publish Portuguese-language documentation or target Lusophone markets specifically

## Suggested follow-ups
- Investigate CasaOS's development status and whether the project is effectively abandoned despite its star count
- Compare CasaOS's "100,000 apps" claim vs Setup MNO's curated 65+ apps to understand the quality-vs-quantity tradeoff
- Research whether any competitor has plans to add Docker Swarm or Kubernetes support to narrow Setup MNO's differentiation window
