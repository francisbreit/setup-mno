# F3: Hosting panels with app stores

## Findings

### [1] Hostinger's Application Catalog is a managed PaaS offering 5-10 web apps per plan, not a self-hosted panel
- quote: "Application catalog — Deploy open-source apps in seconds" / "5 Web Apps" on Business plan ($3.79/mo) / "10 Web Apps NEW" on Cloud Startup plan ($7.99/mo)
- url: https://www.hostinger.com/web-apps-hosting
- source_type: primary
- published: 2025 (current pricing page)
- confidence: high

### [2] Hostinger's app catalog is tightly coupled to its proprietary hPanel and managed infrastructure — no Docker Swarm, no custom app selection
- quote: "Build with Node.js, PHP/HTML, WordPress, Website Builder, Horizons" / "Code-first — Deploy straight from IDE - VS Code, Cursor, Claude, or any AI assistant"
- url: https://www.hostinger.com/web-apps-hosting
- source_type: primary
- published: 2025
- confidence: high

### [3] Plesk offers a paid extensions marketplace (not a free app store) with per-server licensing from €6.60/mo to €31.38/mo
- quote: "Web Admin Edition VPS 12.04€/mo — 10 domains" / "Web Pro Edition VPS 18.29€/mo — 30 domains" / "Web Host Edition VPS 31.38€/mo — Unlimited domains"
- url: https://www.plesk.com/pricing/
- source_type: primary
- published: 2025 (updated Jan 2026 pricing announced)
- confidence: high

### [4] Plesk's Extension Catalogue includes Docker, WordPress Toolkit, and SEO tools, but most are paid add-ons or feature-bundled
- quote: "Extensions — Docker (Web Development), WP Toolkit (Featured), Imunify (Most Popular), Acronis Backup" / bundles: "WP pack, Hosting pack, Power pack, Language pack"
- url: https://www.plesk.com/extensions/
- source_type: primary
- published: 2025
- confidence: high

### [5] cPanel's Softaculous-style one-click installer is not natively included — cPanel sells WP Toolkit and WP Squared as separate products starting at $29/mo
- quote: "Solo For freelancers — 1 Account — $29.99/mo" / "WP Squared For 10 WordPress sites (Then $0.40 for each additional) — $84.99/mo"
- url: https://cpanel.net/pricing/
- source_type: primary
- published: 2025
- confidence: high

### [6] CyberPanel is free forever with the core panel, but its WordPress Manager, Backups, and other power features are paid add-ons ($4.99–$7.99/mo each)
- quote: "Free Forever Plan with No Restrictions — CyberPanel itself is free, you can install CyberPanel with OpenLiteSpeed and deploy unlimited super fast websites" / "WordPress Manager $4.99/mo" / "All The Addons $7.99/mo"
- url: https://cyberpanel.net/features/
- source_type: primary
- published: 2025
- confidence: high

### [7] CyberPanel's one-click WordPress install is the primary app — it does not offer a broad app catalog like cPanel/Softaculous
- quote: "One Click Install — Deploy WordPress sites within 1 minute using our brand-new WordPress Manager" / "Docker Manager — Deploy and manage Docker containers with ease"
- url: https://cyberpanel.net/features/
- source_type: primary
- published: 2025
- confidence: high

### [8] CloudPanel is free (community edition) and supports one-click installation of WordPress, PHP, Node.js, Python, and static sites — no broad third-party app catalog
- quote: "Community Edition — 100% Free to use — For commercial & hobby sites" / "Installation Wizard — set up multiple types of software applications: WordPress Site, Static HTML/CSS/JS, PHP, Node.js, and Python"
- url: https://cloudpanel.io/pricing/ and https://cloudpanel.io/features/
- source_type: primary
- published: 2025
- confidence: high

### [9] HestiaCP is free open-source (GPLv3) with a custom Quick Install App system offering ~11 pre-packaged apps (WordPress, Drupal, Joomla, NextCloud, etc.) — no Docker support
- quote: "One-Click Install Apps (Via CLI or Admin Panel) — WordPress, Dokuwiki, Drupal, Grav, Laravel, MediaWiki, NextCloud, OpenCart, Prestashop, Symphony, Joomla" / "Minimum: 1 core CPU, 1 GB Memory, 10 GB Disk"
- url: https://hestiacp.com/features and https://hestiacp.com/docs/contributing/quick-install-app/
- source_type: primary
- published: v1.9.6 (current)
- confidence: high

### [10] All six panels operate on a single-server paradigm with no native multi-server clustering or Docker Swarm orchestration — a fundamental architectural difference from Setup MNO
- quote: HestiaCP: "Minimum CPU: 1 core, 64-bit / Memory: 1 GB" / CyberPanel: "install CyberPanel on DigitalOcean or Vultr" / cPanel: "Available on Cloud/VPS Only" — all imply single-node deployment
- url: multiple (see above)
- source_type: primary
- published: 2025
- confidence: high

### [11] Paid panels (cPanel, Plesk) can cost $30–$85/mo for a single server, while free panels (CyberPanel, HestiaCP, CloudPanel) charge only for optional add-ons — none compete with Setup MNO's "65+ apps in one command" value proposition
- quote: cPanel Solo $29.99/mo, WP Squared $84.99/mo / Plesk Web Pro €18.29–€31.38/mo / CyberPanel add-ons max ~$8/mo / HestiaCP and CloudPanel entirely free
- url: pricing pages cited above
- source_type: primary
- published: 2025
- confidence: high

### [12] Hostinger's VPS hosting at $4.99/mo (with panel) is the cheapest managed option, but limits users to Hostinger's ecosystem and 5-10 pre-selected apps
- quote: "VPS hosting — Get full control with AI-managed VPS" / "Self-hosted n8n — Custom, node-based AI workflows with full control" (promoted as a premium feature)
- url: https://www.hostinger.com/web-hosting and https://www.hostinger.com/web-apps-hosting
- source_type: primary
- published: 2025
- confidence: high

## Dead ends
- DuckDuckGo search results pages returned HTML without rendered search results (JavaScript-rendered content not accessible via simple fetch)
- CloudPanel documentation site (docs.cloudpanel.io) blocked by SSRF protection — could not access detailed app catalog docs
- CyberPanel pricing page and multiple documentation URLs returned 404 errors
- No independent comparison articles (SitePoint, DigitalOcean, Linode) were accessible (404/403 errors)
- Hostinger tutorial pages for application catalog returned 404

## Suggested follow-ups
- Research Softaculous App Installer (the dominant one-click installer sold to cPanel/Plesk hosts) to understand its 400+ app catalog as a baseline comparison
- Investigate CapRover, Coolify, and Portainer as Docker-based "app store" panels that more directly compete with Setup MNO's Swarm approach
- Compare the actual app deployment workflow time (panel vs. Setup MNO) for Portuguese-speaking course creators deploying typical stacks (WordPress + n8n + Moodle)
