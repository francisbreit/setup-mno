# F1: AI Agent Frameworks & Tools — Combo Research

## Findings

### [1] Dify is a production-ready LLM app platform with Docker Compose deployment

- quote: "Production-ready platform for agentic workflow development. Its intuitive interface combines AI workflow, RAG pipeline, agent capabilities, model management, observability features."
- url: https://github.com/langgenius/dify
- source_type: primary
- confidence: high
- Docker image: `langgenius/dify` (multi-container: api, web, worker, db, redis, weaviate/qdrant)
- Resources: CPU >= 2 Core, RAM >= 4 GiB minimum
- Integrations: PostgreSQL, Redis, Weaviate (default vector DB), Qdrant (configurable), Elasticsearch
- Unique: Visual workflow builder, 50+ built-in tools (Google Search, DALL-E, WolframAlpha), LLMOps observability, Prompt IDE

## Key Observations

1. **AutoGen is EOL** — Microsoft recommends Agent Framework (MAF) for new projects. Setup MNO should consider migrating or adding MAF.
2. **Open WebUI (146k stars)** is the dominant AI interface — it already supports Qdrant, PGVector, SearXNG natively. High combo potential.
3. **Dify (149k stars)** is the closest competitor to Open WebUI for workflow-based AI apps. Uses PostgreSQL/Redis/Qdrant.
4. **RAGFlow (85k stars)** is the heaviest but most capable RAG engine — requires 16GB RAM minimum.
5. **Docker Model Runner** is Docker's native answer to Ollama — manages models as OCI artifacts. Could replace Ollama in some combos.
6. **MaxKB (22k stars)** uses PostgreSQL + pgvector natively — perfect fit for Setup MNO's existing PostgreSQL.
7. **CrewAI** is the most popular multi-agent framework but has no Docker image — runs as Python library.
8. **Vane (Perplexica rebranded)** bundles SearXNG — could simplify search deployment in combos.
