# F3: E-commerce and Business Tool Combos

## Overview

Research findings for e-commerce and business tools that can integrate with Setup MNO's existing stack (WordPress, WooCommerce, Ghost, Nextcloud, GLPI, Open Project, n8n, Chatwoot, Twenty CRM). All tools evaluated for Docker deployment, PostgreSQL/Redis compatibility, and n8n integration potential.

---

## 1. Medusa.js

| Attribute | Detail |
|-----------|--------|
| **Repository** | [medusajs/medusa](https://github.com/medusajs/medusa) |
| **License** | MIT |
| **Stars** | 35.2k |
| **Language** | TypeScript / Node.js |
| **Docker Image** | No official Docker Hub image; deploys via `create-medusa-app` CLI or Medusa Cloud |
| **Database** | PostgreSQL (required) |
| **Cache** | Redis (optional, for caching) |

### Unique Value
Headless, composable commerce platform. Modular architecture with commerce modules (products, orders, payments, inventory). Built-in admin dashboard (Vite). Next.js storefront starter included. API-first design allows any frontend.

### Integration with Setup MNO Stack
- **PostgreSQL**: Native support, uses as primary database.
- **n8n**: REST API available for workflow automation (order processing, inventory sync).
- **WooCommerce alternative**: More modern, API-first replacement for WooCommerce if migrating.

### Deployment Notes
- Requires Node.js v20+ and PostgreSQL.
- No official Docker image — requires custom Dockerfile or use Medusa Cloud.
- Resource needs: ~512MB RAM minimum, scales with traffic.

## 3. WooCommerce + ERPNext Combo

| Attribute | Detail |
|-----------|--------|
| **Integration** | ERPNext has built-in WooCommerce connector |
| **Method** | ERPNext > Setup > WooCommerce > New WooCommerce Server |

### Unique Value
Combines WooCommerce's easy storefront with ERPNext's full ERP capabilities (accounting, inventory, manufacturing, HR). ERPNext acts as the "backend brain" while WooCommerce handles the customer-facing store.

### Integration with Setup MNO Stack
- **WordPress/WooCommerce**: Direct connector in ERPNext.

### Deployment Notes
- ERPNext Docker: `frappe/erpnext` image via `frappe_docker`.
- Requires: MariaDB/PostgreSQL, Redis, Frappe framework.
- Resource needs: ~2GB RAM minimum for ERPNext alone.

## n8n Integration Patterns

All tools above support n8n integration via:

1. **REST/GraphQL API triggers** — n8n polls or receives webhooks.
2. **Webhook receivers** — Tools send events to n8n (order created, invoice paid, issue updated).
3. **Database triggers** — n8n monitors PostgreSQL for changes (less recommended).
4. **OAuth2/API Key auth** — Most tools support token-based API authentication.

### Priority n8n Workflows
- WooCommerce order → ERPNext sales order
- Twenty CRM deal won → Invoice Ninja invoice generation
- Chatwoot conversation → Twenty CRM contact creation
- Plane issue created → Chatwoot notification
- Umami traffic spike → n8n alert workflow
